# Changelog / 変更履歴

## 0.11.0 — SharePoint collaboration preview / SharePoint共同編集プレビュー

SharePoint Online上の `.mm` をWindowsの職場アカウントで開き、自動保存と更新の取り込みを試せます。SharePointのファイルメニュー用SPFxパッケージを配布します。実テナントでの動作確認は未実施です。

Open a SharePoint Online `.mm` map using the Windows work account, save edits and receive remote updates. The release includes an SPFx file menu package. Validation uses a simulated service. See the [release notes](docs/releases/v0.11.0.md).

## 0.10.0 — Sand themes / Sandテーマ

Sandを基調とした新しい画面、表示メニューの配色プレビュー、アプリ配布ZIPの構成変更。詳細は[日英リリースノート](docs/releases/v0.10.0.md)をご覧ください。

The Sand interface, theme previews in the View menu, and an updated portable package. See the [bilingual release notes](docs/releases/v0.10.0.md).

## 0.9.0 — First public preview / 初回公開試用版

Initial public release of MindGlider. See the [bilingual release notes](docs/releases/v0.9.0.md) for features, limits and validation. Versions before 0.9.0 were local development iterations, not public releases of this repository.

MindGliderの初回公開版です。[日英リリースノート](docs/releases/v0.9.0.md)に機能・制限・確認内容を記載しています。0.9.0より前はローカル開発中の版で、このリポジトリでの公開リリースではありません。
