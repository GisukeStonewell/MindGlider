# Changelog / 変更履歴

## 0.11.1 — Keyboard focus / キーボードフォーカス

Alt+TabでMindGliderに戻ったときにメニュー操作が残り、ツリーをすぐに編集できない問題を修正しました。[日英リリースノート](docs/releases/v0.11.1.md)

Fixes a keyboard focus issue that blocked tree editing after Alt+Tab returned to MindGlider. [Bilingual release notes](docs/releases/v0.11.1.md)

## 0.11.0 — AI editing and diagnostics / AI編集・診断

F12のタイトル変更モード、ツリー再構成の差分確認と一括適用、CLIの診断ログ、起動中の更新通知と再起動を追加しました。ノード追加・移動・削除のキー操作、日本語IME、設定保存時の動作を改善しました。[日英リリースノート](docs/releases/v0.11.0.md)

Adds title-only AI editing, tree restructuring with diff review and batch application, CLI diagnostics, and restart notifications after executable updates. Improves node keyboard controls, Japanese IME handling, and saving settings. [Bilingual release notes](docs/releases/v0.11.0.md)

## 0.10.0 — Sand themes / Sandテーマ

Sandを基調とした新しい画面、表示メニューの配色プレビュー、アプリ配布ZIPの構成変更。詳細は[日英リリースノート](docs/releases/v0.10.0.md)をご覧ください。

The Sand interface, theme previews in the View menu, and an updated portable package. See the [bilingual release notes](docs/releases/v0.10.0.md).

## 0.9.0 — First public preview / 初回公開試用版

Initial public release of MindGlider. See the [bilingual release notes](docs/releases/v0.9.0.md) for features, limits and validation. Versions before 0.9.0 were local development iterations, not public releases of this repository.

MindGliderの初回公開版です。[日英リリースノート](docs/releases/v0.9.0.md)に機能・制限・確認内容を記載しています。0.9.0より前はローカル開発中の版で、このリポジトリでの公開リリースではありません。
