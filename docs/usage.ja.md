# MindGlider

Windows 11向けの、Rust＋egui／eframe＋wgpuによるマインドマップエディターです。
Freeplaneの`.mm`ファイルを読み書きし、選択したツリーをCodex／Claude CodeのCLIで編集できます。

## 起動

ポータブルZIPを展開し、`mindglider.exe`を起動します。JavaやRustのインストールは不要です。
UIはOSのSegoe UI Variableを使用します。未収録の日本語グリフはOSのYu Gothic UI・メイリオで補います。Segoe UI Variableがない場合はOSのSegoe UIへフォールバックします。フォントファイルは同梱しません。設定と復元データは実行ファイル横の`data`に保存します。
書き込み可能なフォルダーへ展開してください。`MINDGLIDER_DATA_DIR`環境変数で保存場所を変更できます。GUIの表示状態も`data/ui`に保存します。

上部はメニュー→コマンドバー→マップに接するタブの順で表示します。
メニュー、コマンドバー、タブ、ダイアログ、設定はWinUI 3／Fluentのデザイン指針に合わせています。実装はRust＋eguiを維持しています。[デザイン方針](design.md)を参照してください。

## 基本操作

| 操作 | 既定のキー |
|---|---|
| 子／兄弟ノードの追加 | Tab／Enter |
| 親ノードを挿入 | Shift+Tab |
| 本文を編集 | F2、またはダブルクリックでノード上を直接編集 |
| アイコンを選択 | Ctrl+F2（検索・矢印キー・Enter、Escで閉じる） |
| 折り畳み | Space |
| 親／子／兄弟へ選択移動 | 矢印キー |
| 兄弟を並べ替え／階層を変更 | Ctrl＋矢印キー |
| 左右を切り替え | Ctrl+L（ルート直下の枝） |
| 複数選択 | Ctrl／Shift＋クリック、Shift＋背景をドラッグ |
| ノードを移動 | 接続先の左右端へドラッグ。上下へドロップすると兄弟の前後へ挿入 |
| キャンバスを移動 | 背景を左ボタンでドラッグ（中／右ボタンも可） |
| 拡大・縮小 | マウスホイール、倍率スライダー |
| 全体表示 | Home |
| 保存／別名保存 | Ctrl+S／Ctrl+Shift+S |
| Undo／Redo | Ctrl+Z／Ctrl+Y（本文入力中はテキスト欄のUndo） |
| 検索・置換／コマンド検索 | Ctrl+F／Ctrl+P |
| AI編集／出力 | F12／Ctrl+E |

ノード上の編集はEnterで反映、Shift+Enterで改行、Escapeで取り消します。IME変換確定のEnterは変換だけを確定します。
左右端の矢印、または「表示」メニューから、左のアイコンパネルと右のノード書式パネルを開閉できます。左は初期状態では閉じており、両パネルの最後の開閉状態を次回起動時に復元します。左のアイコンはクリックで付け外しでき、複数選択にも対応します。

上下キーは同じ側の表示ノードから座標に基づいて近い候補を選び、階層をまたいで移動します。左右キーはマップ上の左右配置に従って親子へ移動します。移動先がない方向のキーを押すと10px相当スクロールし、押し続けると連続スクロールします。入力欄やノード本文の編集中はマップをスクロールしません。

Altキーでメニューへ移動し、矢印・Enter・Escapeで操作できます。Alt+F/E/V/T/Hでも開けます。

新規マップはルートが楕円、子ノードが下線型です。アイコンは本文の左に並びます。FreeplaneのSVG画像から陰影を簡略化した201種類の図柄から選択でき、先頭・末尾・全アイコンの削除にも対応します。選択ダイアログではDeleteで末尾、Shift+Deleteで全アイコンを削除できます。変更は選択中のノードにまとめて適用され、Undoで戻せます。既存マップの明示的な形状とアイコンIDは保持します。未知のアイコンは疑問符で表示し、元のIDを保存します。

右の編集欄で文字を選択し、B・I・U・S、色、サイズ、リンクを設定できます。
ノート・詳細はそれぞれ折り畳みパネル内にあります。
コネクターは接続元を選び「接続を開始」、接続先を選び「このノードへ接続」で作成します。
条件付きスタイルは選択ノードの書式から名前付きスタイルを作り、条件と順序を指定します。
「適用」でマップに反映します。正規表現の入力途中は下書きとして保持し、不正な条件のまま適用しません。

## AI編集

1. CodexまたはClaude Codeを別途インストールし、通常のCLIでログインします。
2. MindGliderの「設定」で利用するCLI、実行ファイル、必要ならモデルを指定します。固定プロンプトも編集できます。既定の固定プロンプトは選択中のUI言語に対応し、自分で編集した内容は言語変更でも保持します。
   モデル・reasoning／effort候補は既存CLIの設定・キャッシュ・メタデータ問い合わせから取得します。[CLI設定の詳細](cli-options.md)を参照してください。
3. 編集する枝のルートを選び、F12でAI編集を開きます。入力可能なコンボボックスに指示を入力し、Enterで実行します。Escで閉じます（実行中はキャンセル）。
   ダイアログを開くと前回の指示が入力・フォーカスされた状態になり、最新10件をドロップダウンから選べます。履歴は`data/ai-history.json`に保存します。
   完全一致の履歴は先頭へ移動し、10件を超えると最も古い履歴を取り除きます。
4. 構造・対象範囲・競合の検証に成功すると自動反映します。1回のマップUndoで全体を戻せます。

画像本体・選択外の枝・リンク先ファイルの中身は送信しません。選択した枝の本文・ノート・詳細はCLIの接続先へ送ります。
Codexは専用作業フォルダーと読み取り専用sandbox、Claude CodeはRead・Glob・Grepだけを許可した非対話モードを使用します。
固定プロンプトや指示で明示したローカルのナレッジファイルは、読み取り専用ツールで参照できます。通常はリンク先ファイルを自動送信しません。
認証を維持しつつ、ユーザーのフック・MCP等を読み込まない起動設定を使います。モデルの個別指定はMindGlider側で行ってください。
実行中に対象の枝を編集した場合は、AI結果を破棄します。別の枝の編集は続けられます。

## 設定と言語

設定は「表示と言語」「AI CLI」「PDF・印刷」「ショートカット」のページに分かれています。
「表示と言語」で日本語／Englishを切り替えられます。各項目の「既定値」ボタンと「すべて既定値に戻す」を用意しています。
リセットはマップ・タブ・復元データ・翻訳ファイルを削除しません。
実行ファイル横の`locales/ja.json`・`locales/en.json`はUTF-8の編集可能な翻訳辞書です。
値を修正し、設定画面の「翻訳を再読み込み」で反映してください。キーと`{name}`形式の差し込み文字は保持してください。
省略したキーは内蔵の既定文言で補います。JSONの構文エラーは通知され、直前の翻訳を維持します。
`MINDGLIDER_LOCALES_DIR`で辞書の保存場所を変更できます。OS・外部CLI由来のエラー文は元の言語で表示されます。

## 保存と互換性

`.mm`を主形式とし、未知のXML・未編集HTMLを保持します。対応機能と制限は[FEATURES.md](../FEATURES.md)を参照してください。
クローン・暗号化された枝を通常ノードへ変換しません。編集・破壊的な移動は制限します。
未対応HTMLの編集には「簡略化して編集」を明示的に選択する必要があります。
自動保存は30秒間隔で別の復元データへ保存します。通常保存時は元ファイルを`.mindglider-backup`へ10世代保存します。
外部で変更されたファイルへの上書きは停止し、別名保存を案内します。

## 出力・印刷

全体または選択した枝をTXT・Markdown・OPML・PNG・JPEG・SVG・PDF・HTMLへ出力できます。
画像・PDFは折り畳みを展開して出力します。PDFは用紙、向き、余白、1枚への縮小／複数ページ分割を設定できます。
「PDFを開いて印刷」はPDFを既定のビューアーで開きます。プリンターの選択と最終印刷はビューアーの印刷画面で行います。

## アイコン

紙飛行機とマインドマップの枝を組み合わせた専用アイコンを、ウィンドウ・タスクバーとexeファイルに使用します。
編集用SVG、PNG、複数サイズのICOはソースの`assets/icons`に含まれます。

## 開発

Rust stable、Visual Studio 2022以降のC++ビルドツールとWindows SDKを使用します。
Rustのバージョンは`rust-toolchain.toml`に固定しています。

```powershell
./scripts/build.ps1 -Test -Package
```

構造は[docs/architecture.md](architecture.md)、検証結果は[docs/verification.md](verification.md)を参照してください。

ドラッグ中は枝全体が半透明で追随し、接続位置を青いグラデーションで表示します。接続不可の場所は赤になります。ルートの左半分へドロップすると左側、右半分なら右側へ枝が伸びます。左側の枝の子は左端へ、右側の枝の子は右端へドロップしてください。Esc、接続不可の場所、キャンバス外へのドロップは取り消しになります。移動は1回のUndoで戻せます。

下線型ノードの背景色は、本文の文字範囲に適用されます。アイコン、画像、ノート・詳細の領域はその色で塗りつぶしません。

## Freeplaneとの保存互換性

0.9.0からアプリ名・プロジェクト名をMindGliderへ変更しました。設定・復元データを引き継ぐ場合は既存のdataフォルダーを使えます。旧版の専用マップ属性とメタデータは読み取り、新規保存ではMindGliderの識別子へ更新します。

保存する.mmはUTF-8（BOMなし）です。Freeplaneの先頭判定に合わせてXML宣言を付けず、先頭を必ず `<map version="freeplane …"` とします。日本語・絵文字などはXML数値文字参照で出力し、本文・ノート・詳細の文字を保ちます。Shift_JISには変更しません。Freeplane自身がUTF-8のReaderを使用するためです。注釈や未知のXML要素名は意味を保つためUTF-8のまま残す場合があります。
