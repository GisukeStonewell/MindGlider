# MindGlider v0.11.1

## 日本語

- Alt+TabでMindGliderに戻った直後からツリーを操作できるようにしました。ウィンドウがフォーカスを失うとメニュー操作を解除し、アプリ切り替えで押したAltを離してもメニューは開きません。Alt単独とAlt+Fによるメニュー操作は引き続き使えます。

Windows 11 x64では `MindGlider-0.11.1-windows-x64.zip` を展開し、`mindglider.exe` を起動してください。ZIPのSHA-256は `SHA256SUMS.txt` に記載しています。

## English

- Tree editing is available immediately after switching back to MindGlider with Alt+Tab. Losing window focus closes the menu, and releasing Alt after switching apps does not activate it. Alt alone and Alt+F still work for menu navigation.

On Windows 11 x64, extract `MindGlider-0.11.1-windows-x64.zip` and run `mindglider.exe`. Use `SHA256SUMS.txt` to verify the ZIP.
