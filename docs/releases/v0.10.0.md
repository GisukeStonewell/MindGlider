# MindGlider v0.10.0 — Sand

- Sandを基調にタイトル、メニュー、ツールバー、左右パネルを整理し、ファイルタブを画面下部へ移動しました。子・兄弟ノード追加と折り畳みの操作には、それぞれ専用の図柄を使います。
- 「表示 → テーマ」で10色を選択できます。ホバーで一時反映し、クリックで保存します。旧設定でダークを選んでいた場合はSand Nightへ移行します。
- キャンバスは単色です。ノードの既定色が配色に連動します。ズームやフォントサイズなどのドラッグ操作は引き続き使えます。
- Windows x64版は `MindGlider-0.10.0-windows-x64.zip` を展開して `mindglider.exe` を起動してください。対応するソースとビルド手順は、このリリースの「Source code」から取得できます。配布ZIPのハッシュは `SHA256SUMS.txt` に記載しています。

## English

- The Sand interface reorganizes the title bar, menus, toolbar and side panels. File tabs sit at the bottom, and dedicated icons distinguish adding child and sibling nodes from folding branches.
- Choose one of ten palettes under **View → Theme**. Hover to preview and click to save. Previous dark preferences migrate to Sand Night.
- The canvas uses a solid background and default node colors follow the palette. Zoom and font size still support drag controls.
- For Windows x64, extract `MindGlider-0.10.0-windows-x64.zip` and run `mindglider.exe`. Download the corresponding source and build instructions from **Source code** on this release. Check the portable ZIP against `SHA256SUMS.txt`.
