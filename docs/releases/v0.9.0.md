# MindGlider v0.9.0 — 初回公開試用版 / First public preview

## 日本語

FreeplaneをAIを活用してRustへ移植・再実装し、日常的に使う機能へ絞ったWindows 11 x64向けマインドマップアプリを初公開します。作者自身も全機能・全組み合わせを手動検証していないため、試用版（Pre-release）です。

- Freeplane互換`.mm`の読み書き。未知XML・未編集HTMLの保持に配慮。
- ノード編集、左右の枝、折り畳み、ドラッグの半透明表示と接続先ハイライト、Undo／Redo。
- 装飾、ノート・詳細、画像、Freeplane由来アイコン、関連線・クラウド、検索、条件付きスタイル等。
- Codex／Claude CodeのローカルCLIによる選択ツリーのAI更新。API直接呼び出しは非搭載。
- 日本語／English、外部翻訳辞書、保存・復元・バックアップ、各種出力。
- `.mm`先頭のXML宣言によるFreeplaneの誤判定を修正し、日本語等を数値文字参照で保存。

**使い方:** Windows x64 ZIPを展開して`mindglider.exe`を実行してください。Java／Rustは不要、AI機能には別途CLIが必要です。SHA256SUMS.txtでZIPを照合できます。コード署名はしていません。

**制限:** Freeplaneの全機能・完全互換を保証しません。クローン／暗号化枝は編集を制限します。重要なマップはコピーで試し、AI結果は確認してください。CLIの認証・料金は各サービスの条件に従います。

**確認:** 74件の自動テスト、Clippy、選択したGUI／Release確認、Freeplane実ソースによるヘッダー判定・日本語保持の検証。網羅的な手動検証ではありません。

**ライセンス:** GPL-3.0-or-later。上流素材・依存物の通知と対応ソースをZIPにも同梱します。

## English

The first public preview of an AI-assisted Rust port/reimplementation of selected Freeplane features for Windows 11 x64. The author has not manually tried all features or combinations, so this release is marked **Pre-release**.

- Reads/writes Freeplane-compatible `.mm` files, preserving unknown XML and unedited HTML where possible.
- Core editing, left/right branches, folding, translucent drag previews, drop hints and Undo/Redo.
- Formatting, notes/details, images, Freeplane-derived icons, connectors/clouds, search and conditional styles.
- AI updates of selected trees through locally installed Codex or Claude Code CLIs; no direct AI API integration.
- Japanese/English UI, external translation catalogs, recovery/backups and document/image exports.
- Corrected Freeplane header detection and numeric Unicode references in saved `.mm` files.

**Run:** Extract the Windows x64 ZIP and run `mindglider.exe`. Java/Rust are not needed; AI editing requires a separate CLI. Verify the ZIP with SHA256SUMS.txt. Executables are not code-signed.

**Limits:** This is not a complete Freeplane implementation or a full compatibility guarantee. Clone/encrypted branches are edit-protected. Try important maps on copies and inspect AI results. CLI authentication, service terms and charges apply.

**Validation:** 74 automated tests, Clippy, selected GUI/Release checks and header/Unicode checks using actual Freeplane source. This is not exhaustive manual validation.

**License:** GPL-3.0-or-later. Upstream/dependency notices and corresponding source are also included in the ZIP.
