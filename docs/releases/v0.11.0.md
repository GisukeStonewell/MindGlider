# MindGlider v0.11.0 — SharePoint共同編集プレビュー

- SharePoint Onlineの `.mm` を直接開き、Windowsの職場アカウントで自動認証を試します。ローカル編集は認証不要です。
- 自動保存、他の利用者の変更の取り込み、競合時の編集内容の保持を追加しました。
- SharePointのファイルメニューに「MindGliderで開く」を追加するSPFxパッケージを同時に配布します。
- 認証コンポーネントは利用環境でソースからビルドします。組織のアプリ登録・配備手順と、試用時の制限は[セットアップ手順](https://github.com/GisukeStonewell/MindGlider/blob/v0.11.0/docs/sharepoint-preview.md)をご覧ください。
- 仮想SharePointで検証したプレビューです。実テナントへの配備と検証は未実施です。

## English

- Open SharePoint Online `.mm` maps directly and try single sign-on with the Windows work account. Local editing requires no sign-in.
- AutoSave, remote updates, and conflict handling that retains local edits.
- The SPFx package adds **Open in MindGlider** to the SharePoint file menu.
- Build the authentication component locally. See the [setup guide](https://github.com/GisukeStonewell/MindGlider/blob/v0.11.0/docs/sharepoint-preview.md) for organization registration, deployment and preview limits.
- Validation uses simulated SharePoint. Deployment and verification against a live tenant are pending.
