# MindGlider v0.11.0

## 日本語

- **ツリー編集**では、選択した枝のノードを追加・削除・移動・並べ替えできます。差分を確認してからまとめて適用し、1回のUndoで戻せます。既存IDと親が一致する追加は1行の改名候補として表示され、「既存ノードを改名」と「新規ノードとして追加」を切り替えるとその行の差分が更新されます。
- **タイトルのみ変更**では、周囲のノードを参考にCLIが新しいタイトルを返し、MindGliderが選択ノードの本文だけを更新します。
- **CLIと診断ログ**。Windowsで設定が `codex.exe` の場合の検出を改善しました。ログから起動引数・終了コード・反映結果を確認できます。既定で日次ローテーションし、当日を含めて3日分を保持します。CLIの応答本文の記録は設定で有効にできます。
- **キー操作**。Tab／Enterで新規ノードを追加するとすぐに本文を編集できます。上下キーは同じ側・同じ深さのノードを優先します。Deleteで削除すると次の兄弟、前の兄弟、親の順に選択します。
- **ダイアログ**。F12画面は画面内に収まる範囲で幅530ポイント以上を取り、日本語IMEの変換キャンセルで閉じないようにしました。設定は保存すると閉じます。
- **起動中の更新**。同梱の `update.ps1` で旧実行ファイルを退避して置き換えます。更新検知に対応する版が起動中なら、通知から確認して再起動し、作業セッションを復元できます。

Windows 11 x64では `MindGlider-0.11.0-windows-x64.zip` を展開し、`mindglider.exe` を起動してください。ZIPのSHA-256は `SHA256SUMS.txt` に記載しています。

## English

- **Edit subtree** can add, delete, move and reorder nodes within the selected branch. Review the diff and apply the changes as a batch. One Undo restores the branch. When an addition matches an existing ID and parent, it appears as a single rename candidate. Switching between renaming the existing node and adding a new one updates that row's diff.
- **Change title only** provides nearby nodes as context. The CLI returns a new title, and MindGlider updates only the selected node's text.
- **CLI and diagnostics**. Improved Windows detection when the executable is configured as `codex.exe`. Logs record launch arguments, exit codes and whether edits were applied. Daily rotation keeps three calendar days, including today, by default. Response content logging is opt-in.
- **Keyboard controls**. Tab and Enter create a node and start editing immediately. Up and Down prefer nodes on the same side and at the same depth. Delete selects the next sibling, previous sibling or parent, in that order.
- **Dialogs**. The F12 dialog is at least 530 points wide when space permits and stays open when Escape cancels Japanese IME conversion. The settings dialog closes after a successful save.
- **Executable updates**. The bundled `update.ps1` backs up the previous executable before replacing it. If the running version supports update detection, the restart prompt lets you reopen your session in the new version.

On Windows 11 x64, extract `MindGlider-0.11.0-windows-x64.zip` and run `mindglider.exe`. Use `SHA256SUMS.txt` to verify the ZIP.
